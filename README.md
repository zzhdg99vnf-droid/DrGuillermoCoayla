# drcoayla.net — Web del Dr. Guillermo Coayla

Sitio estático (HTML + CSS + JS, sin dependencias) para cirugía de páncreas, hígado, vías biliares, vesícula y hernias.

| Archivo | Contenido |
|---|---|
| `index.html` | Portada: hero animado, especialidades, cuestionario de orientación, trayectoria, testimonios y preguntas frecuentes |
| `pancreas.html` | Página principal de autoridad (enfermedades, cirugías, segunda opinión) |
| `vesicula.html` | Página de captación: colecistectomía laparoscópica |
| `hernias.html` | Página de captación: hernias |
| `assets/styles.css`, `assets/main.js` | Estilos y animaciones compartidos |
| `ESTRATEGIA-Y-COMPETENCIA.md` | Análisis de competencia, embudo y plan de 90 días |

**Cómo verla:** abra `index.html` en el navegador. Para publicarla, suba la carpeta completa a su hosting.

**Pendiente antes de publicar:** fotos en `assets/` (`dr-coayla.jpg`, `dr-coayla-quirofano.jpg`, `og-image.jpg`), N.º CMP/RNE en el pie de página, testimonios reales y revisión médica de los textos.
El número de WhatsApp se cambia en una sola línea: `WA_NUMBER` en `assets/main.js`.
